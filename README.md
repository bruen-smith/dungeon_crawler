# dungeon_crawler
This project was developed mostly as a fun way to learn c++ but it is designed to be a simple text based dungeon crawler based on the roguelike tutorial using C++ and libtcod on roguebasin.com.

## Technical Details
- Language: C++
- Focus: Player Input, Text output, general game stuff.
- Designed for a fun game loop

## Purpose
This project is mostly for learning the basics of c++ and a little further and as such has very little purpose outside simply expanding my horizons however my interest in c++ arose from the highly optimizable something that I'm finding a lot of modern programs don't have much respect for and could use.
(also I do respect that i learned this language on the premise of something that might not be all that true, but I enjoy learning and C++ feels great with how direct it is)
